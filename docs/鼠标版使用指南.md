# 拾页鼠标版使用指南

鼠标版用一只接在手机上的鼠标完成全部操作：

| 鼠标操作 | 效果 |
|---|---|
| 左键单击 | 另一台电脑静默截图，自动解答，手机上只显示答案 |
| 左键双击 | 在答案下方显示解析 |
| 左键长按 | 约每 0.5 秒截一张，松开后把这些截图合在一起解答 |
| 右键 | 每次退一级：解析 → 答案（代码）→ 代码题的思路页 → 目录 |
| 滚轮 | 答案页每格翻一页，按整行对齐；目录页正常滚动 |

界面固定为横屏，字号按“每屏行数”自动确定（默认每屏 12 行），见第 6 节。

它是独立于语音版的另一个解析端，和语音版共用模型配置和截图端。不需要安装 APK，手机用浏览器打开网页即可。

涉及三台设备：

- **解析端**：运行本项目的电脑，负责调用模型、保存记录。
- **截图端**：被截图的 Windows 电脑，运行 `collect` 文件夹里的采集器。
- **手机**：接鼠标，显示答案。

三台设备需要在同一个局域网内。

还可以再加一台**拍照端**（另一台手机或平板）：用它拍下纸上或别的屏幕上的题目，答案同样显示在接鼠标的那台手机上。它与截图端互不依赖，可以只用其中一个，也可以同时用。见第 5 节的“拍照端”。

## 1. 启动解析端

在项目目录执行：

```powershell
npm run start:mouse
```

鼠标版读取同一个 `.env`：`ANALYZER`、`ANALYZER_MODEL`、`ANALYZER_EFFORT`、`DEEPSEEK_API_KEY` 的含义与语音版相同，当前配置使用 DeepSeek。`HOST` 需要是 `0.0.0.0`，手机和截图端才能连上。端口默认 `8790`，可用 `MOUSE_PORT` 修改。

想在手机上换模型时，在 `.env` 里用 `MOUSE_MODELS` 列出 `ANALYZER` 之外还要提供的模型，写法是 `服务:模型名`，多个用逗号分隔，例如：

```text
MOUSE_MODELS=openai:gpt-5.6-sol
```

- 服务可以是 `openai`（用 `.env` 里的 `OPENAI_API_KEY`）、`deepseek`（用 `DEEPSEEK_API_KEY`）、`codex`、`claude`。
- 模型名后面可以再加推理强度，如 `openai:gpt-5.6-sol:high`；不写时是 `low`。同一个模型写两种强度会作为两个选项出现。
- 选哪个模型在手机的目录页上点，见第 5 节的“目录页”。`ANALYZER=openai` 也可以直接把 OpenAI 的模型设为默认。

终端会打印类似内容：

```text
拾页 · 鼠标版: http://localhost:8790/#pair=k7m2pq9xwd
配对码 k7m2pq9xwd | 监听 0.0.0.0:8790 | 解答模型 deepseek-flash
可选模型：deepseek-flash、gpt-5.6-sol。在手机目录页的顶栏切换，选择保存在 data/mouse/model.txt
任务背景（System Prompt）：用记事本编辑 D:\...\data\mouse\system-prompt.txt 并保存，下一次截图起生效
手机浏览器打开 http://192.168.1.100:8790 并输入配对码；截图端地址填 http://192.168.1.100:8790；拍照用的手机或平板打开 http://192.168.1.100:8790/camera
```

配对码是 10 位小写字母和数字，首次启动时生成并保存在 `data/mouse/pair-token.txt`，重启后不变。要更换配对码，删除这个文件后重启；在 `.env` 设置了 `PAIR_TOKEN` 时使用该值。

Windows 防火墙询问时，允许 Node 在当前网络通信。不要把这个端口暴露到公网。

鼠标版和语音版使用不同端口（8790 与 8787），记录分别保存在 `data/mouse/` 和 `data/`，互不影响。采集器同一时间只能连接其中一个。

## 2. 提前设置任务背景（System Prompt）

任务背景告诉模型这次的学科、语言和答题要求。它保存在解析端的一个文本文件里：

```text
data/mouse/system-prompt.txt
```

有两种设置方式，读写的是同一份内容：

- **在解析端电脑上**：用记事本打开这个文件，写好后保存（UTF-8 编码，Windows 11 记事本默认即是）。不需要重启服务。
- **在网页上**：目录页右上角“设置”里的“任务背景”，手机或电脑浏览器都可以。

保存后从下一次截图起生效；已经完成的记录不受影响，为它们补生成解析时仍使用当时的任务背景。

示例：

```text
这是大学程序设计课的在线练习，语言为 C++。
编程题直接给出可以提交的完整代码；选择题给出选项字母和内容。
```

默认界面只显示答案。任务背景里即使要求“给出解析”，单击得到的仍然只有答案，解析在双击时生成，届时会按任务背景的要求来写。

## 3. 启动截图端

`collect` 文件夹里的采集器无需修改，直接使用。按其中的《Windows被采集端启动说明》操作，只有两处不同：

1. 连接窗口里的控制端地址填鼠标版的地址，例如 `http://192.168.1.100:8790`，配对码填鼠标版的配对码。
2. 不需要在解析端打开网页或选择图片来源。采集器连接后，单击托盘图标框选截图区域即可。

解析端重启后，采集器会在几秒内自动恢复连接，不需要重启采集器。重新启动采集器时，新启动的会立即接管。

## 4. 手机连接

1. 用 OTG 转接头或蓝牙把鼠标连到手机，屏幕上出现鼠标指针。
2. 用 Chrome 或 Edge 打开终端打印的地址，例如 `http://192.168.1.100:8790`，输入配对码，点“连接”。配对码保存在这部手机的浏览器里，下次打开自动连接。
3. 顶部显示“截图端已连接”后即可使用。

解析端更新版本后，手机页面需要刷新一次。

首次使用时先在目录页检查操作是否被手机识别：分别点左键、点右键、滚动滚轮，页面底部“输入检测”一行会显示收到的操作。

## 5. 操作说明

### 单击：截图并出答案

- 目录页：左键点空白处（包括顶栏和提示文字）立即截图。
- 答案页：左键点任意位置截取新的一张。为了和双击区分，指令在松开后约 0.3 秒发出。原答案保持显示，新答案完成后自动替换。
- 截图里有题目时，每题一行给出答案；选择题带选项内容。没有题目时显示“未发现题目”。
- 编程题先显示思路页，再进入代码，见下一小节。代码是可以直接提交的完整代码，带行号显示。模型被要求用直白的变量名（`left`、`maxLength`，而不是 `l`、`mx`）、一行只做一件事、不用压缩的技巧写法，并在每个函数和关键步骤上面写一行中文讲解注释；新写的行尽量不超过 60 个字符。代码因此比以前长，要多翻几页。语言按题目或任务背景；需要固定语言时写进任务背景。
- 截图的编辑器里已经写了不少代码时，答案是在你的代码上补全和修改出来的，见下面的“编辑器里已经有代码时”。
- 默认不显示截图和题干。
- 用鼠标看答案时顶栏自动隐藏，整个屏幕都用来显示内容。

### 代码题：先看思路，再看代码

截图是编程题时，答案分成两级，逐级进入、逐级退回：

| 所在位置 | 左键 | 右键 |
|---|---|---|
| 思路页 | 进入代码页（不截图） | 回目录 |
| 代码页 | 截取新的一张 | 回思路页 |
| 代码页，解析已展开 | 截取新的一张 | 收起解析 |

**思路页**在代码写完时显示，一屏以内，字比正文大：

- **题单对照**：标明是“原题”“变式”还是“不在题单”。原题和变式给出题号和题名，属于热题 100 的另有“Hot 100”标记，变式另有一句与原题的差异；不在题单里时给出最接近的一题。
- **分类标签**：所属的数据结构或算法类别，例如链表、哈希表、BFS。
- **思路标签**：解法的关键想法，例如快慢指针、单调栈、分类讨论。
- **题意**：模型对这道题的一句话概括，可以用来核对它有没有读对题。

题单对照是在代码写完之后才做的，所以思路页刚出现时这一行显示“正在对照题单…”，通常几秒后补上结果，此时代码已经可以看了。如果结果到达时已经进入代码页，屏幕下方会出现一条提示，代码不会跳动。

**代码页**是带行号的完整代码，操作与其他答案相同：单击截新图，双击看解析，长按连拍。

- 在思路页长按不会连拍，松开后同样进入代码页；截新图要先进入代码页。
- 在思路页双击只进入代码页一次，不会截图。
- 在目录页，代码题的条目直接显示对照结果和标签；点开后先到思路页。
- 对照用的题单是 [AlgoMooc 200](https://www.algomooc.com/leetcode-animation/algomooc200) 的 200 题，加上 leetcode.cn“LeetCode 热题 100”里不在其中的 3 题（41、108、118），共 203 题，保存在 `src/problem-list.js`，可以换成别的题单。`node scripts/check-problem-list.mjs` 会联网把这个文件与两个网站核对一遍。
- 对照分两步，是两次模型调用：先只看截图解题（这一步不给模型看题单），代码写完后再把模型自己写的题意和代码拿去和题单比较（这一步不带截图）。模型回答的是“题单里最接近的是哪道题、那道题的标准解法要不要改”，程序据此定为原题（不用改）、变式（要改）或不在题单（用不上），题名取自题单。判断仍可能出错。
- 选择题、填空题等其他题目没有思路页，仍然直接显示答案，右键回目录。

### 编辑器里已经有代码时

模型答题前先看截图里的代码编辑器，把你自己写的代码（题目自带的函数签名等模板不算）判断为“无”“部分”或“较完整”。

- **无**：从头写一份。
- **部分 / 较完整**：在你的代码上补全和修改，给出改好之后的完整代码。你的思路、函数划分和合理的变量名都保留，没有问题的行原样不动；只有思路本身走不通时才换写法，并在代码第一行说明原因。
- 每一处改动的上面有一行注释：改过的行以“改：”开头，说明原来哪里不对；新补的一段以“补：”开头。这些注释行在代码页用橙色显示，左边有一道竖线，翻页时一眼能找到。没有这两个词的注释只是讲解，下面的代码与你原来的一样。
- 思路页最下面会多一行“已有代码：较完整（或：写了一部分）”，表示这份答案是改出来的。
- 这时双击得到的不是普通解析，而是“你的代码还差什么”，见下一小节。

要让模型看到你的代码，截图区域需要把编辑器框进去；代码超过一屏时用长按连拍，边滚动边截。

### 双击：看解析

- 在答案页双击任意位置，答案下方出现“解析”。第一次需要调用一次模型，等几秒；生成后随记录保存，再次打开立即显示。
- 编程题、编辑器里已经有你的代码时，解析分三段：
  - **还差什么**：先一句话说思路对不对、照现在的代码提交会怎样，再逐条列出差距。
  - **要改的地方**：每处一条，写明位置（截图里编辑器的行号、所在函数和那一行的原文）、现在的问题（尽量带一个会出错的输入）、改成什么、为什么。要新增的代码写“第几行之后”。截图里看不到行号时只用函数名和原文定位。
  - **改完之后**：时间和空间复杂度，以及值得自己测的边界输入。
- 编程题、编辑器是空的时，解析讲思路、关键步骤、为什么正确和复杂度。
- 解析下方附本次截图，可核对截图区域是否正确。
- 模型在解析时如果发现原答案有误，会在该题标注“更正”。
- 在目录页双击某条记录，直接打开并展开解析。在目录页空白处双击按一次单击处理。

### 长按：连拍后一起解答

- 按住左键 0.5 秒后开始连拍，屏幕底部显示“连拍 N 张 · 松开后解答”。适合一屏放不下、需要边滚动边截的长题或多道题。
- 按住期间约每 0.5 秒截一张。实际间隔取决于截图上传速度，本机实测 1500×900 的区域平均 0.5 秒一张，Wi-Fi 较慢或区域很大时会更长。
- 画面没有变化时不重复保存，所以按住不动只会留下一张。
- 松开后，这次按住期间的全部截图作为一条记录一起解答；截图之间重叠的题目只回答一次。
- 一次连拍最多保留 12 张不同画面（`.env` 的 `MOUSE_MAX_FRAMES` 可改），最长 60 秒，达到后自动结束并开始解答。

### 拍照端：用另一台手机或平板拍题

在另一台手机或平板的浏览器里打开解析端地址加 `/camera`（例如 `http://192.168.1.100:8790/camera`），输入同一个配对码。这一页只负责拍和传，答案不在这里显示。

| 按钮 | 效果 |
|---|---|
| 拍一张并解答 | 拍一张，立刻作为一条记录解答 |
| 批量拍摄 | 进入批量：每点一次“拍一张”加一张，拍完点“完成并解答”，这一批作为一条记录一起解答 |
| 取消 | 放弃这一批，已传到电脑的照片一并删除 |

- 批量时已拍的照片在按钮上方排成一行，点右上角的 × 可以去掉某一张。一批最多 12 张，与连拍相同（`MOUSE_MAX_FRAMES`）。
- 照片拍下后立刻在后台上传，所以点“完成并解答”时不用再等。没传上去的会在提交时再传一次。
- 提交之后与截图完全一样：解答、代码题的思路页和题单对照、双击看解析，都在接鼠标的那台手机上；答案一到，那台手机会自动打开它。目录里这类记录标有“拍照 N 张”。
- 拍照端页面底部列出本机提交过的记录和状态（正在解答 / 已解答 / 没有完成），用来确认照片送到了。
- 多张照片内容有重叠时，每道题只回答一次；一道题拍成上下两张也可以。

**两种取景方式**，页面左上角会标明当前是哪一种：

- **实时取景**：页面里直接显示摄像头画面，点一下拍一张，批量时最快。浏览器只允许 `https://` 地址和 `localhost` 这样做，所以需要按 README 的“Wi-Fi HTTPS”一节配置证书，或者用第 8 节提到的 Chrome 设置把解析端地址设为可信。
- **系统相机**：用普通 `http://` 地址打开时自动采用，不需要任何配置。每点一次按钮会打开手机自带的相机，拍完确认后照片回到页面；批量时就是这样一张一张加。

照片在上传前会缩小到长边 2400 像素。拍的时候让题目尽量占满画面、避免反光；字太小看不清时模型会回答“无法确定”。

### 右键：每次退一级

- 解析展开时：收起解析，回到只有答案的状态。
- 代码题的代码页：回到思路页。
- 代码题的思路页，或其他题目的答案页：回到目录页。
- 目录页：不做任何事。

### 目录页

- 每条记录显示标题和答案摘要；连拍的记录标有截图张数，拍照端送来的记录标有“拍照 N 张”。
- 左键点某条记录重新打开，不会截图。
- **选模型**：`.env` 里配置了 `MOUSE_MODELS` 时，顶栏“截图端已连接”旁边并排列出可选的模型，高亮的是当前在用的。左键点另一个即切换，不会截图。
  - 从下一次截图或拍照起生效，正在解答的不受影响。
  - 选择保存在解析端电脑上（`data/mouse/model.txt`），重启后保留；拍照端送来的照片也用它。
  - 每条记录右侧标着作答的模型，打开后标题行里也有。双击生成解析、代码题的题单对照，都由给出这条答案的那个模型来做；那个模型已经不在列表里时改用当前的。
  - 只配置了一个模型时不显示这一组按钮。
- 失败的记录留在目录里并显示原因，直接再点一次左键重试。

### 其他

- 0.5 秒内的连续单击只算一次。上一张截图还没传回时再点，不会重复截图。
- 可以连续截取多条，解答同时进行（默认 2 条），按完成顺序依次显示。
- 用手指操作时，只有按钮和目录条目有效，点空白处不会截图。答案页顶栏的“‹ 目录”和“解析”按钮只在用手指操作时出现；手指不支持长按连拍。

### 设置（目录页右上角）

- **每屏行数**、**滚轮每格**、**界面方向**：见第 6 节。保存在手机浏览器里。
- **任务背景 / System Prompt**：见第 2 节。
- **振动提示**：保存在手机浏览器里。
- **解答模型**：显示当前用的是哪个模型。切换在目录页顶栏，不在这里。
- **清空目录**：把现有记录和截图移到解析端的 `data/mouse/archives/`，不删除。
- **断开配对**：清除手机上保存的配对码。

## 6. 横屏与每屏行数

### 横屏

界面固定为横屏：

- 手机横放并且系统已经转成横屏时，页面直接按横屏显示。
- 手机锁定了竖屏（没有打开自动旋转）时，网页无法改变手机本身的方向，页面会把自己的内容转 90°，横放手机即可阅读。这种情况下鼠标指针的移动方向与画面不一致（鼠标向右，指针在画面里向上或向下）。单击、双击、长按、右键和滚轮不需要对准位置，不受影响；要在目录里点选条目时会别扭。**打开手机的自动旋转**后指针恢复正常。
- “界面方向”有三个选项：**横屏**（默认，内容的上边朝向手机右侧，即手机顶部朝左横放）、**横屏（反向）**、**跟随手机**（不自转，竖屏时按竖屏显示）。

### 每屏行数

答案页的字号不是固定的像素值，而是由“每屏行数”决定：屏幕短边除以行数就是一行的高度。答案里的所有内容都排在这个行距上，所以一屏正好是整数行，滚轮翻页不会把一行切成两半。

滚轮每格的翻动量可选：**翻一页**（默认，保留上一页最后一行作为衔接）、**翻半页**、**翻 3 行**。翻动时右下角短暂显示“第几页 / 共几页”，右侧细条表示当前位置。超出屏幕宽度的代码行会折到下一行，行号只标在每个源代码行的开头。

### 小米 14 上选多少行

小米 14 的屏幕是 6.36 英寸、2670×1200，横放时约 147 mm 宽、66 mm 高。用 Chrome 打开时，状态栏、地址栏和手势条占去一部分，网页实际可用的高度约 50 mm。按这个高度估算：

| 每屏行数 | 行距 | 代码字高 | 中文字高 | 每行约可容纳 | 看得清的最远距离 | 看着舒适的距离 |
|---|---|---|---|---|---|---|
| 10 | 5.0 mm | 3.8 mm | 3.4 mm | 55 列 | 约 58 cm | 约 46 cm |
| **12（默认）** | 4.2 mm | 3.2 mm | 2.9 mm | 65 列 | 约 48 cm | 约 38 cm |
| 14 | 3.6 mm | 2.7 mm | 2.5 mm | 78 列 | 约 41 cm | 约 33 cm |
| 16 | 3.1 mm | 2.4 mm | 2.2 mm | 90 列 | 约 36 cm | 约 29 cm |

作为对照，手机上常见的正文字号（16 px）字高约 2.5 mm，对应上表的 14 行。

- **12 行**适合手机放在桌上、离眼睛 40–50 cm 的情况：字比平时的手机正文大约 15–25%，一行能放下约 65 个字符，短代码基本不折行。
- 手机离得更远（50 cm 以上）选 **10 行**；拿在手里看选 **14 行**。
- 表中的距离按显示器人机工效中常用的两条线估算：大写字母高度对应的视角不小于 16 角分为可读下限，20 角分以上较舒适。可用高度 50 mm 是估计值，没有在真机上测量。因为字号按行数计算，实际可用高度不同时每屏行数不变，字的大小会相应变化，按实际观感在设置里调整即可。
- 地址栏占掉约 9 mm。浏览器进入全屏或以“添加到主屏幕”的方式打开时可用高度更大，同样的行数字会更大，可以相应多选两行。
- 手机锁定竖屏、由页面自转时，短边没有被地址栏占用，同样的行数字会更大，而一行能容纳的字符更少，建议改用 14 或 16 行。

## 7. 右键在不同手机上的表现

安卓手机对鼠标右键的处理不统一：有的把右键事件交给网页，有的系统直接把右键当作“返回键”。两种情况页面的表现相同：解析展开时先收起，再按一次回目录；在目录页按返回不会退出页面。

“输入检测”一行显示“右键”或“系统返回键”，可以看出这部手机属于哪一种。

如果右键后两者都没有显示，说明系统或浏览器没有把右键交给页面。可依次尝试：换用 Chrome 或 Edge；在手机的鼠标设置中查看右键功能选项；用手指点答案页顶栏的按钮，或使用系统返回手势。

## 8. 保持亮屏

手机熄屏或锁屏后，鼠标点击不会到达网页。

用普通 `http://` 地址访问时，浏览器不允许网页阻止熄屏。任选一种办法：

- 把手机“自动锁屏 / 休眠”时间调到最长；或在开发者选项中开启“充电时保持唤醒”并接上电源。
- 在手机 Chrome 打开 `chrome://flags/#unsafely-treat-insecure-origin-as-secure`，填入解析端地址（如 `http://192.168.1.100:8790`）并启用，之后网页可以保持亮屏。
- 按 README 的“Wi-Fi HTTPS”一节配置证书，用 `https://` 地址访问。

设置页面里会显示当前是否已保持亮屏。

## 9. 常见问题

**点左键提示“截图端未连接”**

确认截图端的采集器仍在运行，托盘图标显示已连接；地址中的端口是鼠标版的端口。

**提示“请先点击采集端托盘图标选择截图区域”**

在截图端单击托盘图标，框选区域并确认，再点一次左键。

**提示“截图端没有及时传回截图”**

采集器 12 秒内没有上传截图，常见原因是正在框选区域或网络不通。单击的截图在 1 分钟内补传到达时仍会解答。

**提示“上一次截图还没有结束”**

上一次连拍或截图还在进行，等它结束后再操作。

**想单击却进了连拍，或想双击却截了两次图**

按住超过 0.5 秒算长按；两次点击间隔超过 0.3 秒算两次单击。

**一直显示“与电脑断开，正在重连”**

检查手机和解析端是否在同一个 Wi-Fi，解析端服务是否仍在运行。访客 Wi-Fi 常常禁止设备互访。

**答案里出现 `$...$` 或 `\frac` 之类的符号**

提示词已要求模型不用 LaTeX；个别回答仍可能带有。可在任务背景里再强调一次“公式用普通文字书写”。

**想先不花模型额度试流程**

用 `ANALYZER=demo` 启动。每次截图返回占位答案（含一段约 40 行的代码）和占位解析，可用来检查截图区域、每屏行数、双击、长按、滚轮翻页和右键。第 2、4、8、10 次截图的占位答案模拟“编辑器里已经有代码”的情况，带“改：”“补：”注释和“还差什么”式的解析。

**换成 gpt-5.6-sol 后提示 “OpenAI API 返回 …”**

后面的数字是 OpenAI 返回的状态码。常见的是模型名写错（404，`MOUSE_MODELS` 里的名字要与账号能用的模型完全一致）、推理强度不被该模型支持（400）、密钥无效（401）、余额或额度不足（429）。一直没有结果、最后提示超时，多半是电脑连不上 `api.openai.com`，需要代理时按 README 的“OpenAI API 直接解题”一节配置。提示“尚未配置 OPENAI_API_KEY”时在 `.env` 里填上密钥后重启。

## 10. 数据位置

- `data/mouse/system-prompt.txt`：任务背景。
- `data/mouse/state.json`：记录、答案和解析。
- `data/mouse/images/`：截图，以及拍照端送来的照片。
- `data/mouse/incoming/`：拍照端已经传到、但那一批还没有提交的照片。提交后移入 `images/`；取消、放置 15 分钟或解析端重启时删除。
- `data/mouse/archives/`：清空目录时归档的记录和截图。
- `data/mouse/pair-token.txt`：配对码。
- `data/mouse/model.txt`：目录页上选中的模型。删除后回到 `ANALYZER` 指定的那个。

解析端重启后目录保留；重启时尚未完成的记录标记为中断，需要重新截图。
