# 企业手撕题题单

更新日期：2026-10-13。

鼠标版答完一道代码题之后，会把它和题单对照，在思路页显示“原题 / 变式 / 不在题单”。题单原来只有 203 道力扣题。这份文件记录第 8 轮加进去的另一部分：公司面试里要求当场手写、而那 203 道题里没有的题，下面叫“企业手撕题”。目前 28 道，都来自字节跳动的面试。

题目本身和每道题的题意在 [src/problem-list.js](../src/problem-list.js) 的 `COMPANY_LIST` 里。这里记的是每道题出自哪里、被报告过几次，以及这些数字能说明什么。

## 1. 数字是怎么来的

两个来源，都是 2026-10-13 取的。

**牛客网的面经。** 用牛客的站内搜索跑了 86 组搜索词（“字节 手撕”“字节 一面 手撕”“字节 Agent 开发 手撕”等，再加每道候选题各一组），每组取最新的 60 条和最相关的 60 条（不登录时搜索只给这么多），去重后是 2791 篇帖子，其中 2025-01-01 之后的 1584 篇取了全文。

一篇帖子同时满足下面三条，才算对某道题的一次报告：

1. 标题只谈字节：标题（没有标题时是正文第一行）提到字节、抖音、飞书、TikTok、剪映等，没有提到别的公司，也不是“汇总”“合集”。
2. 不是汇总号发的：在这批帖子里发了 6 篇以上、或者开了付费专栏的账号不算。这样的账号有 27 个，共 353 篇帖子，内容多是转述别人的面经。
3. 是当作代码题问的：题目紧跟在“手撕”“手写”“算法题”这类词后面，而且不是在问原理、区别。

满足前两条的帖子有 929 篇，来自 753 个账号。第三条由程序按固定的写法匹配，28 道题一共匹配到 220 篇（文字相同的重复发帖只算一篇）。这 220 篇逐篇读过，去掉 57 篇（问的不是这道题，或者不是让写代码），留下 163 篇；另有 2 篇是读别的题时发现的。合计 165 篇。表里“牛客一手帖”一列就是读过之后留下的篇数。

**CodeTop（codetop.cc）。** 它按公司统计面经里出现的题目，字节名下 873 道题、11773 次记录，是多年累计的（记录里最早的日期在 2020 年）。力扣上没有的题它叫“补充题”，字节名下有 21 道。

这些数字能说明什么、不能说明什么：

- **是下限。** 几家公司写在一起的帖子、标题没写公司的帖子都没有算；搜不到的帖子也没有算。
- **只能比较相对多少，不是出现的概率。** 929 篇帖子里有多少篇写了手撕题、写得全不全，没有统计。
- **两列不能相加。** 牛客一列是 2025 年 1 月以来的，CodeTop 一列是多年累计的。
- **帖子是不是真实面试，无法核实。**

## 2. 入库规则

满足下面任意一条就入库：

- 牛客一手帖至少 2 篇；
- CodeTop 的字节记录至少 10 次；
- 使用者点名（合并嵌套 JSON）。

另外有一条排除：实质上就是那 203 道力扣题里某一道的，不入库，对照时仍然显示成那道力扣题。

## 4. 关于“合并嵌套 JSON”

一手帖只有 1 篇：2026-08-27 的[字节 Agent 开发日常实习一面](https://www.nowcoder.com/feed/main/detail/d2cf5165d1184b59879eff5793b7b453)，里面有完整的规则，题单里的题意就是照它写的。

另外有 7 篇帖子提到这道题，来自两个汇总号，其中一个开了付费专栏。它们写的规则和上面这一篇一致（字典递归合并、列表拼接），有的多了追问；其中两篇连前面几道八股题的顺序都和这一篇一样。这两个账号的帖子是转述还是另有来源，无法判断，所以这 7 篇没有算作独立的报告。

也就是说，这道题确实在字节的 Agent 开发面试里出过，但“高频”这一点目前没有互相独立的帖子支持。它是使用者点名加入的。

汇总号的帖子里提到的追问：key 冲突而且两边类型不同怎么办；列表里的元素是字典时，按某个字段去重之后再合并。

## 6. 怎么加题

在 [src/problem-list.js](../src/problem-list.js) 的 `COMPANY_LIST` 末尾加一行：

```
E29 题名｜公司｜题意
```

- 编号接着往下排。公司写简称，页面上显示成“字节手撕”这样的标记；加别的公司的题，把公司一栏换掉即可。
- 题意写最常见的那种问法，一两句话，说清给什么、求什么、关键规则是什么。对照时模型看不到别的，只凭这一句认题；规则写得越具体，“变式”一栏说的差异越有用。
- 同时改 [test/mouse-core.test.js](../test/mouse-core.test.js) 里的题数。改完重启鼠标版才生效。

重新统计牛客的数字：`node scripts/company-problems.mjs --collect`（几千次请求，约 20 分钟，帖子存在 `data/nowcoder/`，不入库），之后不带参数运行只重算。它给的是读之前的匹配数，要用 `--show E2` 这样把段落打出来读过才能用。给别的公司统计，需要改脚本里判断公司的那两条规则和搜索词。
