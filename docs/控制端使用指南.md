# 拾页控制端使用指南

## 最新简化口令

- **拍**：立即采集一张（旧口令“拍摄”仍兼容）。
- **答案**：回答最新拍取的一张；默认只有题号和完整答案内容，选择题包含字母及选项内容，不给解析。
- **全部答案**：按拍摄顺序回答所有批次中尚未成功回答的图片；跳过正在回答和已成功回答的图片。静默整理不算已回答。失败图片下次仍可重试。

“全部答案”固定触发时已采集的范围，后续新图不加入本次任务。原有启动、长程、停止及带前缀的自由提问仍可使用。下文旧示例可作兼容用法参考，日常优先使用这三个简化口令。

控制端负责语音监听、指挥截图、静默分析、保存结果和回答问题。被采集端只需运行截图脚本并完成一次框选，无需打开网页。

## 1. 启动与连接

在控制端项目目录打开 PowerShell：

```powershell
cd 'D:\hackson\openai 2609\camera-study-assistant'
npm start
```

保持这个终端运行。若控制端已经启动，不要重复启动，否则会提示端口被占用。

打开终端打印的 `http://localhost:8787/#pair=...` 地址，点击 **连接会话**。本机网页使用 `localhost`，便于申请麦克风权限；被采集端脚本使用控制端的局域网 IP。

另一台电脑按《Windows被采集端启动说明》启动脚本，输入同一个配对码并框选区域。然后在控制网页点击 **检测配对**：

- “配对成功”：采集器已收到并确认检测指令。
- “采集器未连接或已离线”：检查另一台电脑的脚本是否仍在运行。
- 检测超时：采集器可能正在上传，或网络不畅，稍后重试。

检测配对不会截图，也不验证图片分析或语音服务。首次连接后，建议点击 **拍摄** 并用“查看”检查截图区域。

配对码以当前服务终端输出为准。服务重启后需要重新连接网页和采集器；未固定配对码时，重启可能生成新码。

## 2. 设置本次任务背景

展开页面顶部的 **任务背景 / System Prompt**，填写背景和额外指示，点击 **保存任务背景**。

示例：

```text
这是高中数学练习复习。
静默整理时，保留完整题干、选项、公式和图形条件，标记看不清的部分。
我提问时，按题号逐题给出答案，再用简洁步骤说明推导过程。
缺少条件时明确指出，不猜测模糊文字。
使用中文，公式同时给出便于语音理解的表述。
```

如果希望回答更短，可以改为：

```text
这是日常练习核对。回答时先给题号和答案，再用一两句话说明依据。
只有我要求详细解析时，才展开步骤；不能确定时明确说明。
```

设置会保存在控制端。新批次和新问题分别使用创建时保存的提示词，后续修改不会改变正在处理的任务，也不会自动重做历史图片分析。

**System Prompt 用于告诉模型如何整理和回答，不是语音唤醒词设置。** 在这里写入新的唤醒词，不会改变程序支持的命令。

## 3. 开启语音与触发词

点击 **开启语音监听**，允许浏览器使用麦克风。显示 **● 持续监听中** 后再说指令。

当前版本没有“你好拾页”一类独立唤醒词。开启监听后，直接说下面的命令即可。说完稍停顿，系统在收到完整转写后执行。

| 直接说出的内容 | 执行效果 |
|---|---|
| 拍摄 | 立即拍一张 |
| 启动 | 约每隔 1 秒拍一张，共 5 张；第一张约在 1 秒后 |
| 长程 | 约每隔 1 秒持续拍摄，直到说“停止” |
| 停止 | 停止采集本批图片，已收到的图片继续处理 |
| 提问，这一页题目的答案和解析 | 对当前页提问，完成后显示并播报答案 |
| 提问，刚才这批所有题目的答案和解析 | 对当前或最近一批已采集页面提问 |
| 暂停播报 | 暂停答案语音 |
| 继续播报 | 恢复答案语音 |
| 取消任务 | 取消未完成的问答任务，并停止、清空答案播报 |

“拍摄”“启动”“长程”“停止”等控制词应单独说，避免加“请帮我”等前后缀。例如，“启动”可以触发，“请帮我启动拍摄”目前不会触发。程序允许常见句末标点。

问题可用 **请问、请回答、我要提问、开始解答、提问** 开头；建议说“请回答，这一页的答案和解析”。单独说“开始解答”会默认解答当前页。请把触发词与具体问题连着说；分成两句话不会进入持续问答模式。程序也兼容将“提问”转写为“题问”的情况。直接说“这道题怎么做”仍不会触发。

如果不方便讲话，可以在页面的文字指令框输入完全相同的内容，点击 **发送**，或使用拍摄按钮。

## 4. 提问示例与范围

### 当前页

```text
提问，这一页所有题目的答案和解析
提问，只解释这一页的第三题
提问，刚才这一题为什么选择 B？
提问，把这一页的关键知识点总结一下
```

默认问题范围是当前批次或最近批次中的最新一张图片。请明确题号，避免只说“那一道”。当前版本不提供按历史批次名称或日期检索的语音命令。

### 整批页面

```text
提问，刚才这批所有题目的答案和解析
提问，这一批按页面顺序列出各题答案
提问，所有页面有哪些共同的知识点？
```

程序通过“这批”“这一批”“所有页面”“全部页面”等词识别整批提问。“所有页面”指当前或最近的一批，不是所有历史记录。为了稳定触发，优先使用“刚才这批”。

提交问题后，程序固定本次问题的图片范围；之后新拍的图片不会自动加入。远程采集时，会先等采集器处理到提问指令、完成前面的上传，再确定范围。

如果图片还在分析，问题会等待相关图片处理完再回答。无需反复提交同一个问题。

## 5. 一次完整使用流程

1. 连接控制会话，保存本次任务的 System Prompt。
2. 启动另一台电脑的采集脚本并框选，点击“检测配对”。
3. 点击“拍摄”，查看截图位置和清晰度。
4. 开启语音监听，确认显示“持续监听中”。
5. 说 **启动**，完成一组五张采集；需要持续翻页时说 **长程**。
6. 收集完后说 **停止**，等待静默处理完成提示音。
7. 说 **提问，刚才这批所有题目的答案和解析**。
8. 需要中断朗读时说 **暂停播报**；不再需要结果时说 **取消任务**。

重复画面可能复用已有分析结果；整批问答会合并识别出的重复页。采集间隔受网络和机器负载影响，并非严格实时。

## 6. 如何看状态和听提示音

- **已采集**：本批已收到的图片数量。
- **已处理**：已完成、已复用或已失败的图片数量，不等于全部成功；请结合每张图片状态查看。
- **等待中**：尚未处理完的图片数量。
- **查看整理结果**：展开静默分析文字，不会自动朗读。
- **失败详情**：查看该图片的处理错误。
- **重新播报**：重新朗读已完成的问答结果。

批次已结束且所有图片处理完后，控制端播放一次完成提示音；部分失败或采集不完整时使用不同提示音。正在播报答案时，提示音会排在后面。

长程模式要先说“停止”结束批次，才会产生该批最终完成提示音。静默分析不会主动念出结论，只有“提问”触发回答。

## 7. 暂停和退出的区别

| 操作 | 停止的内容 |
|---|---|
| 停止 | 图片采集；分析继续，麦克风监听继续 |
| 暂停播报 | 语音播放；采集和分析继续 |
| 取消任务 | 未完成的问答和答案播报；不会停止截图 |
| 关闭语音监听 | 麦克风监听；可继续使用按钮和文字 |
| 结束会话 | 断开控制网页会话，关闭当前采集批次；已收到图片继续处理 |
| 退出远程采集器 | 退出另一台电脑的截图脚本；需先停止采集 |

使用完毕，先停止采集，再关闭语音监听。需要彻底退出时，结束会话，并在运行服务的终端按 Ctrl+C。退出服务会中断尚未完成的处理任务。

## 8. 常见问题

**监听按钮无法开启**

先确认已连接会话，页面显示语音 API 已配置。检查浏览器麦克风权限，并使用 `http://localhost:8787` 打开控制端页面。看页面顶部的具体错误；“无法连接语音服务”通常需要检查运行服务的环境能否联网、API 配置及账户权限。

**显示持续监听，但指令没生效**

观察“听到的话”是否出现转写。单独说准确的控制词，或以“提问”开头说完整问题，句末稍作停顿。声音过轻、环境噪声和扬声器回声都会影响识别，可先用耳机测试。

**点击拍摄没有图片**

先检测配对，并确认图片来源选择了“远程电脑屏幕”。采集端需保持登录、未锁屏，脚本仍在运行。控制端服务重启后，采集端脚本也需要重新启动。

**图片一直处理中或处理失败**

展开失败详情。在控制端 PowerShell 运行 `codex login status` 检查 CLI 登录。首次 OCR 会下载语言数据，模型分析也需要网络；长时间无进展时应检查服务终端。重启会中断未完成任务，之后需要重新拍摄。

**有文字答案但没有声音**

确认没有暂停播报，检查页面错误、系统音量和浏览器自动播放限制；点击答案下的“重新播报”。TTS 的 API 调用权限与 Codex CLI 登录分别配置。

**找不到最新按钮或页面状态不更新**

刷新网页后重新连接。建议只保留一个控制页面会话，当前版本不支持多个控制页面同时连接。

## 9. 模型速度设置

当前使用 `deepseek-flash` + `low` effort，静默整理与答案解析均直接调用 DeepSeek Responses API，并附带原图。语音继续使用 OpenAI，OCR 去重继续使用本地 Tesseract。项目 `.env` 的 `ANALYZER_MODEL` 与 `ANALYZER_EFFORT` 控制图片整理和问答模型；修改后重启服务生效，不更改全局 Codex 配置。更轻量候选为 `gpt-6-sol`，需结合实际题目评估准确率。降低 effort 可能缩短推理时间，但 OCR、CLI 启动和网络仍有开销。

## DeepSeek 配置（当前运行方案）

`ANALYZER=deepseek`、`ANALYZER_MODEL=deepseek-flash`、`ANALYZER_EFFORT=low`，密钥存于本机 `.env` 的 `DEEPSEEK_API_KEY`。静默整理和答案解析均使用 DeepSeek，并发送对应原图、任务背景和问题上下文。STT/TTS 仍使用 `OPENAI_API_KEY`。切换回 Codex 时将 ANALYZER 改为 codex，同时将模型名改为可用的 Codex 模型，然后重启。图片处理与语音 API 分别计费。
