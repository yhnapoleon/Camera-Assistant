# 手机摄像头学习助手 · 设计

独立项目，用户于 2026-09-24 授权开始设计和构建。手机保持前台亮屏，录音与摄像头由手机网页采集。电脑保存资料、调用语音 API、运行 Codex/Claude Code。

## 已确认行为
- 拍摄：立即单拍；启动：第 1/2/3/4/5 秒各拍一次；长程：每秒拍摄直到停止。
- 停止仅终止新增采集，队列继续处理。重复帧也计入批次完成。
- 逐张静默分析，保存时间戳、图片、OCR、结论；绝不自动将分析文字送入 TTS。
- 关闭批次且所有帧处理完，提示音一次；部分失败使用不同声音。播报中延后提示音。
- “提问”前缀创建任务；“这一页”取最新帧，“这批/这一批/所有页面”冻结当前批次已接收帧。等待已入队帧分析后逐个唯一页面解题，汇总答案解析。新帧不加入旧问题。
- 暂停播报、继续播报、取消任务与停止拍摄分开。

## 技术选择
- Node 22 ESM，原生 HTTP/HTTPS + ws；无前端构建步骤。
- STT: gpt-live-transcribe，通过服务器 WebSocket，24 kHz PCM16；手机 AudioWorklet 分块，电脑能量 VAD 检测停顿并 commit。仅最终转写触发指令，同一 item_id 幂等。设置 languages=[zh]、关键词提示，turn_detection=null。
- TTS: gpt-4o-mini-tts，marin，可配置。API 生成 MP3，网页分段顺序播放；暂停/恢复本地播放。
- 第一版分析采用官方 Codex 非交互 CLI（--image、只读沙箱、独立工作目录、结果文件）；可选 Claude Code Read 工具。每张分析独立调用，上下文显式持久化，避免历史无限膨胀。后续可替换为常驻 App Server。
- 本地 Tesseract eng+chi_sim OCR + sharp 视觉特征。仅文字长且高度相似、画面亦相似时复用；无文字仅字节完全相同才跳过，保守防止漏图表。保存 duplicateOf。
- 批次与任务元数据落盘 JSON；原始图片本地保存。进程重启时未完成项目标为中断，不假装已处理，可重新提交。
- 控制命令严格匹配，否定句和背景闲聊不触发；完成提示音用 Web Audio 合成，无 API。

## 协议与可靠性
- 手机与电脑单一 WebSocket，认证配对 token；HTTP 图片/TTS/状态亦要求 token。API key 仅服务器环境变量。
- 单一活动控制手机，断线自动关闭采集批次，手机停计时；已接收图片保留并继续处理。
- frame 使用 batchId + frameId 幂等，finish 在所有上传完成后发送。接收超过上限显式报错并停止采集，不静默丢帧。
- 分析串行；问答任务使用独立队列，避免拍照命令被长模型调用阻塞。取消任务中止当前模型进程，且不继续播报。
- 提问时网页先等待当时已拍照片上传，然后冻结范围。问题页面含多题，要求按题号完整输出，模糊项标注。
- TTS 播放期间继续麦克风采集并请求浏览器回声消除；只接受严格控制短语和“提问”前缀。实际扬声器回声/噪声下识别需真机验证，可使用耳机。

## 部署与验收
- localhost 可先在电脑体验。安卓 USB 使用 adb reverse tcp:8787 tcp:8787 + http://localhost:8787；Wi-Fi 使用 HTTPS，需安卓信任本地 CA。不会自动安装根证书或改防火墙。
- API key 未配置时显示未配置；提供明确 demo 模式，仅模拟分析，不声称模型联调成功。
- 自动测试：否定句/重复转写、队列串行、去重、完成提示一次、上传幂等、批量冻结、失败继续、取消任务、HTTP 鉴权、STT payload/VAD。
- 实机验收：手机相机权限、后置对焦、1s 实际节拍、中文命令、回声、STT/TTS 账号可用性、Codex 模型图片能力。

## 当前边界
前台单设备 MVP；长程上限按待处理容量控制；非离线唤醒。API 与模型额度分别受对应账户限制。没有公开稳定的桌面 Codex 语音转接接口，因此不把桌面语音作为手机 TTS。

## 首轮测试：Windows 远程固定区域
- 2026-09-24 补充：一次性小悬浮框进入区域选择，选完后两个窗口全部关闭并释放；正常运行不再显示 UI，终端退出即结束采集器。无需被采集端网页。控制端支持区域坐标调整与退出命令。
- 控制端可保存任务背景（System Prompt），批次和问题分别固定创建时的版本；提示词变化不复用旧分析结论，历史问答仅引用同背景任务。
- 用户确认目标电脑为 Windows，允许自己启动一次采集程序。控制网页和麦克风放在本机；目标电脑运行 PowerShell 采集器，首次框选后按固定坐标截图。
- 采集器主动连接服务器，以配对码认证。命令轮询带确认序号，图片上传以帧 ID 幂等；采集完成后关闭批次，分析逻辑与手机一致。
- 远程提问作为采集器命令屏障，在已拍图片上传后冻结范围，避免依赖两台电脑时钟同步。断线关闭批次并保留已收到的图片。
- 目标电脑需保持登录和屏幕可见。采集器不会操作鼠标键盘；DPI、遮挡、多显示器与实际网络节拍留待真机验证。
