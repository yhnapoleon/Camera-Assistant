# 拾页：另一台 Windows 电脑启动说明

这台电脑只负责固定区域截图，不需要打开网页，也不需要安装 Node.js、Python、Codex 或配置模型 API key。使用 Windows 自带的 Windows PowerShell 即可。

运行流程：**启动 → 输入地址和配对码 → 点击托盘图标选区 → 确认 → 等待控制端指令。**

## 1. 启动前准备

两台电脑接入同一个局域网。下面称运行网页和分析模型的电脑为“控制端”，被截图的电脑为“采集端”。

控制端先完成：

1. 在项目 `.env` 中设置 `HOST=0.0.0.0` 和 `PORT=8787`，然后在项目目录运行 `npm start`。已有服务需先退出再重启。
2. 运行 `ipconfig`，记下当前联网网卡的 IPv4 地址，例如 `192.168.1.100`。
3. 打开服务终端打印的网页地址，点击“连接会话”，图片来源选“远程电脑屏幕”。
4. 记下终端网址中 `pair=` 后面的配对码。服务重启后配对码可能变化，以最新输出为准。
5. 如防火墙询问，允许 Node 在专用网络通信。

把下面文件复制到采集端的同一个文件夹即可：

- `screen-agent.ps1`（启动入口）
- `ScreenAgent.cs`（托盘界面、选区与通信实现，启动时自动编译，无需安装开发工具）
- `start-agent.vbs`（无控制台窗口启动入口）
- 本说明文件

> 文中 IP 只是示例，必须替换成控制端真实 IP。采集端不能使用 `localhost` 或 `127.0.0.1` 连接控制端。当前本机的 `8788` 演示预览仅供本机查看；远程测试请按上面的局域网配置启动服务，并使用实际端口。

## 2. 在采集端运行

推荐双击 `start-agent.vbs`。在连接窗口填写控制端地址和配对码，点击“连接”。配对码仅本次使用，不写入配置文件。

启动后只有通知区域中的**蓝色圆形取景框图标**，没有常驻窗口或任务栏窗口。Windows 决定图标显示在任务栏还是向上箭头的折叠面板中，可在任务栏设置中调整。

也可以在 PowerShell 中执行（此方式保留你手动打开的终端）：

```powershell
powershell -NoProfile -STA -File .\screen-agent.ps1 -ServerUrl http://192.168.1.100:8787
```

在弹出的连接窗口中输入配对码。自动化启动也可传入 `-PairToken` 参数。这里使用的是配对码，不是 OpenAI API key。

## 3. 从托盘选择或调整截图区域

1. 将需要截图的页面或窗口摆好。
2. 单击蓝色取景框托盘图标，或右键选择 **重新选择区域**。
3. 按住鼠标左键拖出截图矩形，松开后可继续调整。选区外会变暗，选区显示物理像素尺寸和坐标。
4. 拖动选区内部可移动，拖动八个边角调整点可改变大小；方向键微调 1 像素，Shift + 方向键微调 10 像素。也可在选区外重新拖框。
5. 点击 **确认区域** 或按 Enter 应用；点击 **取消**、按 Esc 或鼠标右键取消并保留原区域。
6. 遮罩关闭后继续等待控制端指令。再次修改区域仍从托盘图标进入，无需重启。

选区时暂停截图上传，但继续保持控制端心跳；确认或取消后恢复原有批次。首次启动尚未选择区域时不会截图，控制端触发采集会收到需要选区的提示。

正常采集时不会弹窗、发出声音或逐张打印记录。连接成功本身不会开始上传截图，只有收到控制端采集指令才开始。

**保持托盘采集器运行。** 被截图的内容需要保持可见。目标电脑应保持登录、未锁屏；窗口最小化或被其他窗口遮挡后，截到的是当前屏幕实际显示的内容。右键托盘图标可查看连接状态、当前区域或退出。

## 4. 后续全部在控制端操作

| 操作 | 效果 |
|---|---|
| 拍摄 | 立即截取一张 |
| 启动 | 每隔约 1 秒截取一张，共 5 张 |
| 长程 | 每隔约 1 秒持续截图 |
| 停止 | 停止本批截图，已接收图片继续处理 |
| 提问，这一页题目的答案和解析 | 基于当前页回答 |
| 提问，刚才这批所有题目的答案和解析 | 基于本批页面回答 |

按钮和文字指令可直接使用；语音指令需在控制端配置语音 API 并开启麦克风监听。批次完成提示音和答案播报都在控制端播放。

控制端顶部可展开 **任务背景 / System Prompt**，填写背景和额外指示后保存。新批次与新问题使用保存后的内容，正在处理的任务保持原设置。

可以直接在采集端点击托盘图标重新选区。原有控制端 **远程截图区域与采集器** 中的物理像素 X、Y、宽、高设置仍可使用；本地选区过程中收到的远程区域变更会被忽略，避免干扰确认或取消操作，请在本地选区结束后再应用远程坐标。

## 5. 退出与下次启动

- 在采集端右键蓝色取景框图标，点击 **退出采集器**。
- 也可先停止采集，再在控制端点击 **退出远程采集器**。在线状态最多需要约 15 秒更新。
- 下次使用时双击 `start-agent.vbs`，输入地址和当前配对码，再从托盘选择区域。
- 短暂网络故障会保留托盘图标并自动重试；受影响的采集批次会结束，恢复连接后可从控制端发起新批次。配对失效时托盘显示相应状态，请退出后使用有效配对码重启。
- 右键菜单 **重新连接** 可立即重试。运行日志保存在同目录 `capture-agent.log` 中，配对码不写入日志。

## 6. 常见问题

### 提示无法连接、连接被拒绝或超时

先确认控制端服务仍在运行、IP 和端口正确、`HOST=0.0.0.0` 已生效。采集端可执行以下只读连接检查：

```powershell
Test-NetConnection 192.168.1.100 -Port 8787
```

`TcpTestSucceeded: False` 表示网络连接尚未打通。检查两台电脑是否在同一可互通网络、是否启用了访客 Wi-Fi 隔离，以及控制端防火墙是否允许该端口。

### 提示配对失败或 401

重新复制控制端当前服务终端网址中 `pair=` 后面的完整内容。不要复制整个网址，不要包含空格。

### 提示已有屏幕采集器在线

当前版本只接受一个采集器。退出先前运行的脚本，等待约 15 秒后重试。

### 提示禁止运行脚本或文件未签名

这是该电脑的 PowerShell 执行策略。可先用以下命令查看：

```powershell
Get-ExecutionPolicy -List
```

如为组织管理的电脑，使用组织允许的脚本运行或签名方式。脚本本身不会修改执行策略；不要为运行它永久放宽整台电脑的策略。

### 截图位置不正确或画面被遮挡

点击托盘图标重新框选。分辨率、缩放比例、显示器排列或窗口位置改变后，原坐标可能不再适用。第一次联调先从控制端点“拍摄”，查看返回图片后再开始连续采集。

HTTP 地址用于受信任局域网测试。截图会上传到控制端，配置真实分析模式后由相应模型处理。请只框选本次任务需要的内容。
