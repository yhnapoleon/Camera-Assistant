这两道题的完整资料在生成答案前提供给模型：原题优先沿用参考解法，变式按当前题面修改并说明差异；不相关题目忽略参考资料。继续保留分步教学和 LeetCode / ACM 双模式，匹配结果标为“华为笔试”。原题判断仍由模型完成，不是确定性 OCR 检索或逐字代码回放。其余题单继续在答案生成后做对照。

新增题库需要重启解析服务才能生效，刷新网页不会重载服务端题库；采集端地址不变时无需重启采集端。已有记录不自动重算。参考代码通过附带的三个样例；RMSNorm 在 `l>0、energy=0、epsilon=0` 时原题未定义除零行为，题库明确保留这一限制。

## 编程题分步学习（2026-10-28）

鼠标版新扫描的编程题一次生成完整学习内容，阅读顺序为：

**分类/思路概览 → 思路分析 → 具体实现 → 结构图解 → 代码**。

- 分析页说明为什么选择该方法、正确性依据和复杂度；实现页以 S1、S2 等编号讲解变量、操作和边界。
- 图解支持缩放、滚动；点击节点或实现步骤可定位对应代码块。
- 代码采用 VS Code 风格高亮、行号和步骤分块。长代码行按手机／平板可用宽度自动折行，保持原始行号与缩进；复制仍得到未折行的源代码。默认 **LeetCode 核心解法＋完整本地入口、测试数据与必要结构定义**；点击 **ACM** 切换标准输入输出方案，两者不需要重新调用模型。
- “复制完整代码”包含本地入口；“复制提交代码”仅复制 LeetCode 核心部分。运行命令、样例输入和预期输出在代码下方。题面未指定标准输入格式时，ACM 说明明确标为“本地约定”。本项目不执行模型生成的代码，预期输出仍需本地核验。
- 顶部阶段按钮、前进和返回按钮支持鼠标及触摸。鼠标点非交互空白处逐步前进，右键逐级返回；到代码页后，空白处单击截新图、长按连拍。代码选择、复制、图解操作和模式切换不触发截图。
- 多题可按题号切换；同批普通题在概览保留答案和独立的解析入口。
- 旧记录继续使用原来的思路/代码界面，不自动重新分析。需要新版内容时重新截图。生成内容被截断或缺少必需字段时会明确失败，可在记录中点“使用原图重试”。

首次生成比原来的单份代码输出更长。每次少量题目效果更稳定，遇到模型超时或输出上限可减少同批题目数量后再试。

本地界面演示（独立临时数据，不调用模型、不影响历史记录）：

```powershell
node scripts/preview-lesson.mjs
```

打开输出的 `http://localhost:8792/#pair=lesson-preview`，点击“演示：两数之和”。以下旧版说明中“思路后直接进入代码”的行为，仅适用于旧记录。

## 最新简化口令

- **拍**：立即采集一张（旧口令“拍摄”仍兼容）。
- **答案**：回答最新拍取的一张；默认只有题号和完整答案内容，选择题包含字母及选项内容，不给解析。
- **全部答案**：按拍摄顺序回答所有批次中尚未成功回答的图片；跳过正在回答和已成功回答的图片。静默整理不算已回答。失败图片下次仍可重试。

“全部答案”固定触发时已采集的范围，后续新图不加入本次任务。原有启动、长程、停止及带前缀的自由提问仍可使用。下文旧示例可作兼容用法参考，日常优先使用这三个简化口令。

独立于 meeting-agent。手机前台网页拍摄或 Windows 固定区域截图 → 电脑静默整理 → 批次完成提示音 → 用户提问才回答、播报。

## 鼠标版（手机接鼠标触发）

另一个独立的解析端，支持鼠标截图和语音问答，手机用浏览器即可，不需要 APK：

- 首页顶栏点 **语音问答** 进入新模式：左键点击页面空白处开始录音，右键结束，随后自动转写问题并给出答案与简明解析。也可使用页面上的开始、结束和取消按钮。
- 语音问答无需连接截图端。转写使用 `OPENAI_API_KEY` 与 `VOICE_STT_MODEL`（默认 `gpt-transcribe`），答案沿用首页选中的模型和任务背景。设置后重启 `npm run start:mouse`。本次实现为结束后转写，不是边说边转写。
- 麦克风要求 HTTPS 或 localhost；Android USB 初测可执行 `adb reverse tcp:8790 tcp:8790` 后打开 `http://localhost:8790`。普通局域网 HTTP 地址无法申请麦克风权限。
- 安卓 Wi-Fi 录音可额外启用 HTTPS `8791`，保留现有 HTTP `8790` 和截图端配置；两个入口共用同一个会话。配置与手机安装证书步骤见 [安卓 Wi-Fi 语音配置](docs/安卓WiFi语音配置.md)。

- 左键单击：截图端静默截图，自动解答，手机上只显示答案。
- 左键双击：显示解析（此时才调用模型生成）。
- 左键长按：约每 0.5 秒截一张，松开后把这些截图一起解答。
- 代码题先显示思路页：分类标签、思路标签，以及与题单的对照（原题 / 变式 / 不在题单）；左键再进入代码，在代码页左键才截新图。题单是 AlgoMooc 200 加上热题 100 的其余 3 题，再加 28 道字节面试里的企业手撕题（见 [docs/企业手撕题.md](docs/企业手撕题.md)），对照在代码写完之后才做，晚几秒补到思路页上。
- 代码用直白的变量名并带讲解注释。编辑器里已经写了不少代码时，答案是在这份代码上补全和修改的，改动处有“改：”“补：”注释；此时双击显示“还差什么、改哪一行、为什么”。
- 可以在目录页顶栏切换解答模型：在 `.env` 用 `MOUSE_MODELS=openai:gpt-5.6-sol` 之类的写法列出 `ANALYZER` 之外的模型。
- 右键每次退一级：解析 → 代码 → 思路 → 目录；滚轮按整行翻页。
- 拍照端（可选）：另一台手机或平板打开 `/camera`，点按钮拍一张或一批，之后的解答流程相同，答案显示在接鼠标的那台手机上。
- 界面固定横屏，字号按“每屏行数”确定（默认 12 行，可调），代码带行号显示。
- 任务背景（System Prompt）写在解析端的 `data/mouse/system-prompt.txt`，可提前编辑。

```powershell
npm run start:mouse
```

默认端口 8790，与语音版共用 `.env` 的模型配置和 `collect/` 采集器（采集器无需修改），记录保存在 `data/mouse/`。用法见 [docs/鼠标版使用指南.md](docs/鼠标版使用指南.md)。

## 模型选型

| 用途 | 第一版选择 |
|---|---|
| 持续 STT | `gpt-live-transcribe`，服务器连接 Realtime transcription，仅输出文字 |
| TTS | `gpt-4o-mini-tts` + `marin`，外接 API；可在 `.env` 换声音 |
| 图片整理 / 解题 | 已登录的 Codex CLI，或 `ANALYZER=claude` 使用 Claude Code |
| OCR 去重 | 本地 Tesseract，英文 + 简体中文；OCR 不可用时仍做完整视觉分析 |
| 批次完成提示音 | 浏览器本地生成，不调用 TTS |

`gpt-live-transcribe` 要求应用检测停顿并提交音频，不能配置 `server_vad`。本项目提供能量门限 VAD、24kHz PCM 与最终转写去重。实际噪声和口音需要实测调参。语音 API key 与 Codex/Claude 登录分别配置。

官方文档：[实时转写](https://developers.openai.com/api/docs/guides/realtime-transcription)、[TTS](https://developers.openai.com/api/docs/guides/text-to-speech)。

## 本机先运行

要求 Node.js 22+。在本目录执行：

```powershell
npm install
Copy-Item .env.example .env
```

编辑 `.env`，把 `OPENAI_API_KEY` 填入本机文件。不要把它发到网页或远程电脑。

- 真实分析：`ANALYZER=codex`，先确保 `codex login` 已完成；也可设置 `ANALYZER=claude` 并先登录 Claude Code。
- 不调用模型的流程演示：`ANALYZER=demo`。演示文字均明确标注，不能作为真实答案。
- `ANALYZER_MODEL` 留空沿用本机 CLI 默认模型；可填该账户实际可用、支持图片的模型名。
- OCR 首次加载会下载语言数据；网络不通时可先设 `OCR_ENABLED=false`，只做完全一致图片去重。

```powershell
npm start
```

打开终端输出的 `http://localhost:8787/#pair=...`。点“连接会话”。API key 尚未配置时，按钮、文字命令、静默处理和完成提示音仍可测试，语音识别/播报会显示未配置。

## 首选测试：另一台 Windows 电脑固定区域截图

本机：

1. `.env` 设置 `HOST=0.0.0.0`，重启服务。
2. 用 `ipconfig` 查看本机的局域网 IPv4 地址。本机控制网页仍打开 `http://localhost:8787`，这样麦克风处于安全上下文。
3. 如 Windows 防火墙询问，允许专用网络的 Node 连接。不要将此服务暴露到公网。
4. 控制网页选择“远程电脑屏幕”。

被截图电脑：

1. 复制 `scripts/screen-agent.ps1` 到该电脑。不需要安装 Node/Python。
2. 在普通 Windows PowerShell 运行（把示例 IP 替换为本机地址）：

```powershell
powershell -NoProfile -File .\screen-agent.ps1 -ServerUrl http://192.168.1.100:8787
```

3. 输入本机终端 URL 中 `pair=` 后面的配对码（不是 OpenAI API key）。
4. 启动时显示一次小悬浮框，点击“Select capture region”后拖出截图矩形；按 Esc 可取消。选完后悬浮框和选区遮罩全部关闭并释放，本次运行不再出现。
5. 控制网页显示采集器已连接后，使用“拍摄 / 启动 / 长程 / 停止”。被采集端不需要网页；PowerShell 可最小化，正常采集不弹窗、不播放声音、不逐帧打印。Ctrl+C 或关闭这个 PowerShell 窗口即可退出。
6. 如需微调，可停止采集后，在控制网页展开“远程截图区域与采集器”，填写物理像素坐标并应用；也可以从这里退出远程采集器。

若脚本被执行策略拦截，可针对这个已审阅文件在当前 PowerShell 进程设置策略，或按组织策略签名后运行；程序不会自行修改系统策略。

终端会打印坐标，后续可省略框选：

```powershell
powershell -NoProfile -File .\screen-agent.ps1 -ServerUrl http://192.168.1.100:8787 -X 100 -Y 100 -Width 1200 -Height 800
```

固定坐标依赖屏幕分辨率、缩放和窗口位置；改变后应重新框选。目标电脑应保持已登录、未锁屏。截取的是当前可见屏幕区域，被遮挡或最小化的窗口不会自动恢复。不要在采集器的框选区域里放置其终端窗口。

采集器主动连接本机，程序不扫描局域网，也不尝试访问未启动采集器的电脑。HTTP 模式用于受信任局域网的初次测试；要加密图片和配对码传输可使用下面的 HTTPS 配置。

## 手机相机模式

网页切换“本机 / 手机摄像头”，打开相机，允许后置摄像头权限。持续保持页面前台。

### USB 初测

电脑安装 Android platform-tools，手机开启并确认 USB 调试后：

```powershell
adb reverse tcp:8787 tcp:8787
```

手机 Chrome 打开 `http://localhost:8787`，输入配对码。localhost 可以申请麦克风和相机权限。

### Wi-Fi HTTPS

使用 mkcert 在本机为 `localhost`、`127.0.0.1` 和本机局域网 IP 生成证书，将证书放在本项目 `certs/`。安卓安装并信任 mkcert 的 CA **公钥证书**（不要复制私钥）。本项目不会替你修改证书信任库。

```powershell
mkcert -cert-file certs/server.pem -key-file certs/server-key.pem localhost 127.0.0.1 192.168.1.100
```

`.env` 设置：

```text
HOST=0.0.0.0
TLS_KEY=certs/server-key.pem
TLS_CERT=certs/server.pem
```

重启后手机打开 `https://本机IP:8787`。仅跳过证书错误通常不足以获得可靠的媒体权限，应正确建立信任。证书随 IP 变化需更新。

## 交互规则

控制网页顶部提供“任务背景 / System Prompt”。填写本次任务背景、学科、回答格式等并点击保存，设置随本机数据持久化。新批次在创建时固定提示词，新问题在提交时固定提示词；修改设置不改变正在执行的任务，也不会重新处理历史图片。不同提示词的图片不复用静默分析结论。此字段作为任务指示传给 CLI，不覆盖 CLI 自身的系统规则。

- “拍摄”：立即 1 张；“启动”：1s 间隔共 5 张；“长程”：持续直到“停止”。网络或系统负载可能使实际间隔变长，不承诺硬实时。
- “停止”只停止采集，已收到图片继续处理；整批关闭且所有图片处理完，播放一次提示音。部分失败使用低音提示。
- “提问，这一页题目的答案和解析”：最新页面；“提问，刚才这批所有题目的答案和解析”：当前/最近批次。
- 问题范围固定后新图不加入；重复页只解一次，页内多题按题号输出。
- “暂停播报 / 继续播报 / 取消任务”：控制语音和问答，不改变拍摄。
- 远程截图模式在采集器处理到问题命令时冻结范围，保证它正在上传的截图先到达；不是按两台机器未经校准的时钟硬切分。
- 本地图片上传也支持批量，可用于同一套固定测试图片的重复测试。

## 保存与测试

- `data/images/`：采集图片，适合作为稳定测试集。
- `data/state.json`：批次、时间戳、OCR、静默结论和问答。重启后未完成工作标记为中断。

- 运行 `npm test`，包含命令分流、截图节拍、上传屏障、去重、串行处理、批次完成、问答范围、取消、鉴权、远程采集协议、STT 过期消息及 TTS 取消的测试。

## OpenAI API 直接解题

设置 `ANALYZER=openai`、`ANALYZER_MODEL=gpt-6-luna`、`ANALYZER_EFFORT=low`，重启服务后直接调用 OpenAI Responses API，支持单图、多图和不带图的题单对照，省去每次启动 Codex CLI 的开销。`OPENAI_API_KEY` 可以从启动服务的进程环境继承，无需写入 `.env`。API 调用按 API 账户计费。

网络需要 HTTP 代理时，可在本机 `.env` 配置 `HTTPS_PROXY=http://代理地址:端口` 和 `NODE_OPTIONS=--use-env-proxy`（Node.js 22.21+ 或 24.5+），使 `npm start` / `npm run start:mouse` 也启用代理。本机实测仅在 `.env` 设置 `NODE_USE_ENV_PROXY=1` 时连接超时，显式启用该选项后正常。响应耗时仍取决于题目、输出长度和网络。

## DeepSeek 配置

`ANALYZER=deepseek`、`ANALYZER_MODEL=deepseek-flash`、`ANALYZER_EFFORT=low`，密钥存于本机 `.env` 的 `DEEPSEEK_API_KEY`。静默整理和答案解析均使用 DeepSeek，并发送对应原图、任务背景和问题上下文。STT/TTS 仍使用 `OPENAI_API_KEY`。切换回 Codex 时将 ANALYZER 改为 codex，同时将模型名改为可用的 Codex 模型，然后重启。图片处理与语音 API 分别计费。
